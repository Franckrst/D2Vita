# ux0:data/d2vita/controls.txt — reference copy, every key the game reads
#
# This file was copied here automatically on first boot (never overwritten
# after that — delete it and it will be re-seeded from the VPK next boot).
# Everything below is a comment: nothing is actually remapped by this file
# as shipped. Uncomment a line and change its value to change that binding;
# lines the game does not recognise are now reported in boot_progress.txt
# as "controls.txt ignore ...", instead of silently doing nothing.
#
# Full walkthrough: https://franckrst.github.io/D2Vita/controles/
#
# One "key=value" per line. Blank lines and lines starting with # are
# skipped. Whitespace around key/value is NOT trimmed — keep both flush
# against the '='.

# ---------------------------------------------------------------------------
# Button names (case-insensitive): cross/croix, circle/rond, square/carre,
# triangle, up, down, left, right, start, select. Prefix with "r+" or "l+"
# for that combo layer (never both on the same line).
#
# Action names (case-insensitive):
#   lclick  rclick  none
#   alt  shift  tab / automap  esc / echap
#   items   — item assist (see below); also spelled item_assist / assist
#   inv  perso  skills  quests  swap  space  run  enter
#   pot1  pot2  pot3  pot4
#   f1  f2  f3  f4  f5  f6  f7  f8
#   vk:0xNN   — raw Windows virtual-key code, hex or decimal
#
# Item assist (action "items"): HOLD the button it is bound to. The game
# shows the ground-item name labels (it is Alt held, for the game) and, while
# you hold, the D-pad jumps the cursor from label to label and Cross picks
# the highlighted item up. With no item on the ground the D-pad and Cross
# keep their normal bindings. Any button, layer, l=, r= or select= can carry
# it; "alt" stays a plain Alt. Example:  square=items
# ---------------------------------------------------------------------------
