# after that — delete it and it will be re-seeded from the VPK next boot).
# Everything below is a comment: nothing is actually remapped by this file
# as shipped. Uncomment a line and change its value to change that binding;
# lines the game does not recognise are now reported in boot_progress.txt
# as "controls.txt ignore ...", instead of silently doing nothing.
#
# Full walkthrough: https://franckrst.github.io/D2Vita/controles/
#
# One "key=value" per line. Blank lines and lines starting with # are
# skipped. Whitespace around key/value and a trailing "# comment" are fine.

# General tuning
# ---------------------------------------------------------------------------
#orbit=70          # direct-movement radius, px (left stick, orbits the cursor)
#sens=18           # right stick speed (free cursor: menus, panels, aiming)
#deadzone=0.15     # stick deadzone, a fraction 0..0.9 (0.15, NOT 15)
#anchor_y=470      # character's vertical screen anchor, per-mille of a 1000-tall canvas
#diamond=on        # off = hide the aim assist's diamond (the aim itself still works)
#
# A number outside its range is refused and reported in boot_progress.txt:
#   orbit 10..400, sens 1..100, deadzone 0..0.9, anchor_y 100..900, orbit_min/
#   orbit_max 5..400, cone 5..90, hover_h 0..150, hud_h 0..300, reach 50..2000,
#   hostile_reach 100..2000
#   (orbit=1000 from older builds is NOT valid: it breaks the walking).

# ---------------------------------------------------------------------------
# Button names (case-insensitive): cross/croix, circle/rond, square/carre,
# triangle, up, down, left, right, start, select. Prefix with "r+" or "l+"
# for that combo layer (never both on the same line).
#
# Action names (case-insensitive):
#   lclick  rclick  none
#   alt  shift  tab / automap  esc / echap
#   items   — item assist (see below); also spelled item_assist / assist
#   aim     — aim assist (see below); also spelled aim_assist
#   inv  perso  skills  quests  swap  space  run  enter
#   pot1  pot2  pot3  pot4
#   f1  f2  f3  f4  f5  f6  f7  f8
#   vk:0xNN   — raw Windows virtual-key code, hex or decimal
#
# Item assist (action "items"): HOLD the button it is bound to. The game
# shows the ground-item name labels (it is Alt held, for the game) and, while
# you hold, the D-pad jumps the cursor from label to label and Cross — or L,
# when L is the aim button — picks the highlighted item up. With no item on the ground the D-pad and Cross
# keep their normal bindings. Any button, layer, l=, r= or select= can carry
# it; "alt" stays a plain Alt. Default:  square=items
# ---------------------------------------------------------------------------

# ---------------------------------------------------------------------------
# Aim assist (action "aim"): HOLD the button it is bound to. In game it acts
# on the best target: your own corpse in reach, else what the cursor sits on,
# else the enemy in a cone around the cursor, else the nearest chest / door /
# NPC. It borrows the cursor and hands it back. Bound to L by default (out of
# game, and in menus, the same button is a plain left click).
#
# While "aim" is bound the STICKS run in aim mode in game: left stick = walk
# only (never attacks), right stick = free cursor. Set "l=lclick" (and bind
# it nowhere else) for the legacy scheme instead: left stick = direct
# movement (orbiting cursor + held click), right stick a free mouse. Any
# button, layer, l=, r= or select= can carry aim. Example:  cross=aim
# The feeding hooks are only installed while "aim" is bound.
#
# Optional tuning (only used while aim is bound):
#orbit_min=40      # walk-ring radius at a light push, px at 600 lines
#orbit_max=110     # ... at full push
#cone=35           # half-angle of the aim cone around the cursor, degrees
#hover_h=28        # default hover height above a unit's feet, px
#hud_h=60          # bottom band assisted clicks never enter, px
#reach=300         # reach for chests/doors/NPCs, world units
#hostile_reach=800 # reach for monsters, world units (closest to the cone axis wins)
# ---------------------------------------------------------------------------
