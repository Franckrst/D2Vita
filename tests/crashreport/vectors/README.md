# Contract vectors (copy)

Byte-for-byte copy of `contract/vectors/` from `github.com/Franckrst/D2Vita-website`
(API v1 contract). Never edit these files by hand: regenerate them in the contract
(`contract/tools/gen_vectors.py`) and copy them again with
`tools/tests/sync_contract_vectors.sh`, which also checks that the copy is current.
